The Buttons folder contains a sampling of premade buttons that you can add to one of the template files in order to print to add to your Extron Crosspoint 450, Crosspoint Ultra, DXP DVI, or DXP HDMI.

Included are some examples of format conversions, displays, and scalers. The "Extra Templates" folder contains various template files that you can use with the logos in the "Video Game System Logos" folder to create most any button you may need.

You can also use those logos with the Touchscreen Button.psd template to create new buttons for the CRT-Control Super.
