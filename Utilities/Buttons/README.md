The Buttons folder contains a sampling of premade buttons that you can add to one of the template files in order to print to add to your Extron Crosspoint 450, Crosspoint Ultra, DXP DVI, or DXP HDMI.

Included are some examples of format conversions, displays, and scalers.   
[Conversions](Utilities/Buttons/Conversions) contains a small sample of buttons used for denoting format conversions such as HDMI to YPbPr and 480p to 480i.  
[Displays](Utilities/Buttons/Displays) contains premade buttons for various display types, output types, and resolution combinations.  
[Extra Templates](Utilities/Buttons/Extra-Templates) contains various template files that you can use with the logos in the [Video Game System Logos](Utilities/Buttons/Video-Game-System-Logos.zip) zip folder to create most any button you may need.  
[Scalers](Utilities/Buttons/Scalers) contains premade buttons for various retro scalers. Right now just the post-2X RetroTinks.  

You can also use those logos with the [Touchscreen Button.psd](Utilities/Buttons/Extra Templates/Touchscreen Button.psd) template to create new buttons for the Super CRT-Control.
